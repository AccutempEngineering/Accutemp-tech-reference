# Accutemp Field Reference

Live page: https://accutempengineering.github.io/Accutemp-tech-reference/
Supply House Finder: https://accutempengineering.github.io/Accutemp-tech-reference/supplyfinder/

* **cards.js**: every card, section, filter chip and source link. This is the only file to edit for content. See [CONTRIBUTING.md](CONTRIBUTING.md).
* **index.html, app.js, styles.css**: the page itself (search, filters, layout).
* **sw-ref.js, app.webmanifest, app-icon-*.png**: offline use and the home screen icon.
* **refs/**: PDFs and images the cards link to.
* **tools/**: checks and the git-history date script.
